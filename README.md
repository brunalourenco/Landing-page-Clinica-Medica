# Landing Page para Clínica Médica
O projeto tem como objetivo divulgar os serviços médicos prestados pela Clínica e auxiliar na prospecção de clientes. 
Auxiliar pacientes e funcionários com a divulgação dos dias e horários de consultas por especialidades médicas.

# Responsividade
Para melhor usabilidade foram utilizados recursos de responsividade e assim a landing page funciona em vários dispositivos.
Em relação a largura de tela para foram considerados:
- Celulares -até 425px;
- Tablets - até 768px
- Computadores - até 1024px
- A landing page também funciona em telas maiores que 1024px
